## Learned User Preferences

- Prefer READMEs that lead with project or domain narrative, not module lists, file inventories, or build/run instructions
- Still include numbered indexes (question/topic tables) in folder READMEs for programs and flowcharts
- Subdirectory READMEs should end with a parent back-link in the style `← Back to CSC101-1`
- Prefer flat descriptive `.c` filenames for lab and assignment programs rather than numbered `N/main.c` subfolders
- Flowchart exports should be compressed WebP with name and register number removed
