# Library Management

These labs share one desk: **library membership and overdue fines** — take a member and a few books in, compute per-book and total fines, then decide whether a student discount applies and whether more issues are allowed.

Lab 1 starts with the operator drills that feed that desk (`type()`, arithmetic, relational/logical, assignment), then lands on the fine report itself. The same billing shape shows up earlier in practice as a supermarket bill.
