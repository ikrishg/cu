# STA161-1 — Computational Statistics

Excel-first coursework for cleaning, shaping, and analysing datasets — the kind of ledger and operations data a sales or logistics desk actually keeps.

Labs walk through the spreadsheet toolkit in order: how the workbook UI fits together, importing messy tables, splitting and formatting contacts, text and conversion functions, then logical and date work on ecommerce, sales, and HR-style ledgers. CIA and ESE apply the same cleanup habit to fuller datasets, including a sales-division analysis and a separate project workbook.
