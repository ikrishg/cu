# Hobbit

WAD labs for **Hobbit** — a hobby- and activity-centric social platform for logging books, film, games, music, fitness, and the rest of a life offline. The course walk builds the pitch site from HTML through CSS, JavaScript, and a PHP + MySQL registration backend; the SRS sketches the fuller product (feeds, profiles, chat, recommendations).
